## Product Context
- **What this is**: 浏览器原生论文工作流 + 跨 AI agent 的本地知识层（MCP server）。
- **Who it's for**: ML / CV / AI / NLP PhD / Master 学生（office-hours sub-persona 决议）。次要：工业研究员。
- **Space/industry**: 学术/科研工具。竞品：Zotero, NotebookLM, Obsidian + Citations, Glasp, arXiv-sanity, Elicit。
- **Project type**: Chrome MV3 扩展（popup + sidepanel + onboarding + content script hover badges）+ marketing 入口（GitHub README / 首页）。
- **Memorable thing**: "研究者的 portable brain — 把每篇论文都接进任何 AI 的本地知识层。"

## Aesthetic Direction
- **Direction**: Industrial × Editorial。安静、密集、学术尊严感。Anti-SaaS、Anti-friendly-toy、Anti-enterprise-dashboard。
- **Decoration level**: Minimal → Intentional（细 grain texture 仅在 hero / empty state）
- **Mood**: 像 Linear meets Nature 期刊封面 meets arXiv 自身的克制。
- **Reference vibe**: Linear（数据密度）+ Nature/Quanta Magazine（serif 优雅）+ Substack 后台（克制 grayscale）。

## Typography

所有字体均为 **SIL OFL-1.1**，AGPL-3.0 + 商业用途完全兼容。

| Role | Font | Why | Usage |
|------|------|-----|-------|
| **Display** | Fraunces (variable serif, opsz + slnt axes) | 优雅 + 印刷品重量 + 学术调；区别于所有用 Inter 的 AI 工具 | README hero / Onboarding 大标题 / Dashboard 大数字 / section headings |
| **Body** | Instrument Sans | 中性 grotesk，比 Inter 有性格，x-height 适中，副 italic 完整 | 论文 abstract / 卡片 / dashboard 文字 / 大段说明 |
| **UI / Data** | Geist Sans (with `font-feature-settings: "tnum"`) | 数字对齐 + UI 节奏 + 紧凑 | 按钮 / 表格 / KPI / status bar / 小标签 |
| **Mono** | JetBrains Mono | 真等宽 + 字符可识别（0/O 区分）| arXiv ID / GitHub repo path / MCP config / 代码片段 / eyebrow 标签 |

**严格禁用**: Inter, Roboto, Space Grotesk, Open Sans, Lato, Montserrat, Poppins, system-ui-as-display, Helvetica/Arial-as-display。**永远不**自动 fallback 到 system-ui 作为 display 字体。

**加载策略**:
- 开发阶段：`<link rel="stylesheet" href="https://fonts.bunny.net/css?family=fraunces:400,500,600,700|instrument-sans:400,500,600|geist:400,500,600|jetbrains-mono:400,500&display=swap">`
- 生产阶段（建议）：self-host woff2，4 字体共 ~120KB gzipped，无 CDN 依赖
- **不**用 Google Fonts 直接加载（隐私 + 与 ContextOS "本地优先" 叙事冲突）

**Type scale (modular, 1.25 ratio)**:

| `--text-xs` | 11px | mono labels, eyebrows, status |
| `--text-sm` | 13px | UI buttons, table cells, paper meta |
| `--text-base` | 15px | body, paragraphs |
| `--text-md` | 16px | featured body |
| `--text-lg` | 22px | card titles, secondary headings |
| `--text-xl` | 32px | section titles, onboarding headings |
| `--text-2xl` | 48px | display, dashboard big numbers |

**Variable axes（Fraunces 专用）**:
- Hero: `font-variation-settings: "opsz" 144;`

## Color

**Approach**: Restrained — 单一主色（rust）+ 完整中性梯度 + 4 个 semantic 色。**不**用渐变作为主视觉，**不**用紫色，**不**用蓝色作为 brand。

### Palette (Dark default + Light)

| Token | Dark | Light | Use |
|-------|------|-------|-----|
| `--bg` | `#0F0F10` | `#FAFAF7` | page background, paper card bg |
| `--surface` | `#1A1A1C` | `#F2F1EC` | elevated surfaces, sidepanel cards |
| `--surface-2` | `#222226` | `#E8E7E0` | secondary buttons, hover states |
| `--text` | `#E8E6E1` | `#16161A` | primary text |
| `--muted` | `#8A8780` | `#6A685F` | secondary text, eyebrows, status (dual-mode) |
| `--border` | `#2A2A2D` | `#DEDDD7` | dividers, card outlines |
| `--accent` | `#C2410C` | `#C2410C` | **THE only color** — CTA, KPI, citation rule, hover badge highlight |
| `--accent-soft` | `#C2410C26` | `#C2410C1A` | accent button hover bg |
| `--success` | `#15803D` | `#15803D` | "MCP CONNECTED" dot, install OK |
| `--warning` | `#B45309` | `#B45309` | rate limit, deprecation |
| `--error` | `#B91C1C` | `#B91C1C` | failure, destructive confirm |

### Color rules
- **Accent (rust #C2410C) 不可被替换为蓝/紫/绿**。它是 ContextOS 与所有 12 平台 AI 工具的视觉差异化锚点。
- **Dark mode 是默认**。研究者深夜读 paper 是主场景。Light mode 必须可用但不优先优化。
- **不**用半透明色作为主表面。表面层级靠不同 hex 区分。
- 所有 text 与 bg 组合必须 ≥ 4.5:1 contrast (WCAG AA)；UI / labels ≥ 3:1。

## Spacing
- **Base unit**: 4px
- **Density**: comfortable-to-dense
- **Scale**:
  | Token | px |
  |-------|----|
  | `--space-2xs` | 2 |
  | `--space-xs` | 4 |
  | `--space-sm` | 8 |
  | `--space-md` | 12 |
  | `--space-base` | 16 |
  | `--space-lg` | 24 |
  | `--space-xl` | 32 |
  | `--space-2xl` | 48 |
  | `--space-3xl` | 64 |
- **Surface 内 padding**: sidepanel cards 16px, popup cards 12px, modal 24px, marketing 32-64px
- **Stack gap**: 8-16px (dense surfaces), 24-48px (marketing / onboarding)

## Layout
- **Approach**: Hybrid
  - Sidepanel / popup / Settings / Dashboard → grid-disciplined, dense, left-aligned, 12px column gutter
  - Onboarding / Marketing / README / 首页 → editorial, 强 typo hierarchy, 不对称 OK
- **Sidepanel width**: 380px (Chrome 默认)
- **Popup width**: 360px max
- **Marketing max-width**: 1240px
- **Reading max-width**: 760px (paper abstract / docs)
- **Border radius (hierarchical, no bubble-everything)**:
  | Token | px | Use |
  |-------|----|------|
  | `--radius-sm` | 4 | input, paper card, badge, status pill |
  | `--radius-md` | 6 | button, card, panel |
  | `--radius-lg` | 12 | modal, sidepanel container, sheet |
  | `--radius-full` | 9999 | avatar, status dot, pill toggle (sparingly) |

## Motion
- **Approach**: Minimal-functional — 零 scroll-driven animation, 零 floating blob, 零 parallax
- **Easing**:
  | Token | Curve |
  |-------|-------|
  | `--ease` | `cubic-bezier(0.16, 1, 0.3, 1)` (Linear style, default) |
  | `--ease-in` | `cubic-bezier(0.4, 0, 1, 1)` (exit only) |
- **Duration**:
  | Token | ms | Use |
  |-------|-----|-----|
  | `--dur-micro` | 80 | hover state, button press |
  | `--dur-short` | 180 | theme toggle, badge fade-in, dropdown open |
  | `--dur-medium` | 300 | sheet slide, modal enter |
  | `--dur-long` | 600 | dashboard number tick-up (1 次, 不重复) |

## Anti-slop checklist (违反这些 = 砍)
- ❌ 紫/紫罗兰渐变作为 accent
- ❌ 3 列 icon-in-circle feature grid
- ❌ Centered everything 堆叠布局
- ❌ Bubble border-radius (uniform 12-16px on all elements)
- ❌ Gradient buttons 作为 primary CTA
- ❌ Stock-photo hero
- ❌ system-ui 作为 display 字体
- ❌ "Built for X" / "Designed for Y" copy
- ❌ Inter / Space Grotesk anywhere
- ❌ Floating blob / mesh gradient 装饰
- ❌ Parallax / scroll-jacking
